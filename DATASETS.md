# Datasets register

A running record of every dataset polyx has used, under what terms, and for what. Kept as we go, because a vendor-risk questionnaire, a partner's diligence, or an acquirer will ask, and reconstructing it later is far worse.

**Posture:** internal testing and validation only. No dataset is redistributed, and no dataset ships inside the product. Evaluation corpora are kept separable from product artefacts (numbers out, never artefacts in).

| Claude Code transcripts (`cc`) | n/a — the operator's own records | n/a | 2026-09-03 | The first corpus in which the agent under study is an AI agent taking consequential actions against real systems: obligation mining, cross-model provenance, and the segmentation ground truth FS §10.4 asks for | **Private. Never redistributed, and it cannot be: it is one person's own machine.** Frozen from `~/.claude/projects` by `corpora/link-cc.mjs` into `corpora/cc/` (gitignored) — a copy, not a link, because the live directory grows under any run that reads it and a corpus that moves cannot reproduce a figure. 141 sessions, 34 projects, ~103k events. No third party's data is involved and no licence governs it, but it holds file paths, host names, branch names and shell commands, so: command text and file contents are **never persisted** (only the verb, and the path as a redaction token), and every figure it produces is reportable while the corpus behind it is not reproducible by anyone else. Recorded here as a limitation, in the same way BPIC's absent policy document was. The fixture under `test/fixtures/cc/` is hand-authored, not a clipping. |
